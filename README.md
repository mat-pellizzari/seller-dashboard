## SELLER-DASHBORD

A web application for salespeople to track their sales, weekly goals, and work hours.  
Users can log product sales, set weekly targets, and register check-in/check-out times with intuitive charts and statistics.

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Utilities / Tools
- bcrypt (password hashing)
- CORS (cross-origin requests)
- JSON Web Token (authentication)
- Postman (API testing)
